# Code de conduite

Ce projet adopte le **Contributor Covenant, version 3.0** : https://www.contributor-covenant.org/version/3/0/code_of_conduct/

## Engagement

Nous voulons que la participation à ce projet soit une expérience sans harcèlement pour toutes et tous, quels que soient l'âge, l'apparence, le handicap, l'origine, l'identité ou l'expression de genre, le niveau d'expérience, la nationalité, la religion, l'orientation sexuelle ou les opinions politiques. Le sujet du projet (impôts, budget, vie politique) appelle des désaccords : ils portent sur les données et les méthodes, jamais sur les personnes.

## Comportements attendus

- Respect et bienveillance, y compris dans le désaccord.
- Critiques argumentées, sources à l'appui.
- Reconnaître ses erreurs et en tirer les conséquences.

## Comportements inacceptables

- Insultes, harcèlement, menaces, propos discriminatoires.
- Publication d'informations personnelles d'autrui sans son accord.
- Prosélytisme politique ou partisan dans les échanges du projet.

## Signalement et application

Signale tout manquement par message privé aux mainteneurs du dépôt (via leur profil GitHub). Les signalements sont traités avec confidentialité. Les mainteneurs peuvent retirer un contenu et, selon la gravité, avertir, suspendre ou exclure une personne du projet.
